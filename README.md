# Personalify

A personal-first browser music library preview.

## Current preview

- Add local audio files and play them in the browser.
- Search your library, mark favorites, shuffle, repeat, seek, and control volume.
- Export and restore a Personalify `.pfy` backup.
- Responsive dark interface.

## Important limitations

This is a static frontend prototype. Audio files are stored in the browser on the current device; they are not uploaded or shared globally. Clearing browser site data can remove local tracks, so export backups regularly. Accounts, cross-device sync, shared uploads, moderation, and a global music catalogue require a backend and rights-aware hosting. Only upload or distribute music you have permission to use.

## Run locally

Open `index.html` in a modern browser, or serve the repository as a static site. Browser storage must be enabled for the library to persist.
